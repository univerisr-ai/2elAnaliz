# Project Documentation

## Setup
To set up the project, navigate to the root directory and run `npm install` to install the required dependencies.

## Usage
To start the development server, run `npm run dev` in the terminal. This will start the Vite development server, and you can access the application at `http://localhost:3000`.

## Output Location
The built application will be located in the `dist` folder at the root of the project.

## Updates
The following files have been updated:
- `src/App.tsx`
- `src/App.css`
- `src/index.css`
- Files under `src/components`

New components have been added under `src/components` and imported using the existing Vite structure (e.g., `./components/Ad`).

## Notes
The application has been updated to have a modern, premium, and mobile-friendly UI. All import paths have been maintained to be consistent with the existing file structure.
